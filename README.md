# Fitme

Fitme - Android-приложение для планирования тренировок, ведения тренировочного дневника и хранения истории выполненных подходов. Приложение работает локально: основные данные хранятся на устройстве в Room/SQLite, а бизнес-логика вынесена в repository-слой.

## Основные возможности

- создание и хранение профиля пользователя;
- выбор активного тренировочного плана;
- работа с тренировочными планами и шаблонами тренировок;
- справочник упражнений и пользовательские упражнения;
- автоматическое создание следующей тренировки по порядку шаблонов;
- поддержка периодизации упражнений через чередование режимов;
- запись выполненных подходов, веса, повторений и длительности;
- просмотр истории тренировок;
- стартовое заполнение базы данных упражнениями, шаблонами и готовыми планами;
- локальное тестирование backend/data-layer без эмулятора через Robolectric.


Актуальные версии зависимостей находятся в [gradle/libs.versions.toml](gradle/libs.versions.toml). Конфигурация Android-модуля находится в [app/build.gradle.kts](app/build.gradle.kts).

## Требования к окружению

Для сборки и запуска нужны:

- Android Studio с установленным Android SDK;
- Android SDK Platform 36;
- Android SDK Build Tools, совместимые с AGP 9.0.1;
- JDK 21 для Gradle/Kotlin toolchain;
- устройство или эмулятор с Android API 26+ для запуска приложения;
- доступ к Google Maven и Maven Central для первичной загрузки зависимостей.

## Запуск проекта

1. Открыть проект в Android Studio.
2. Дождаться Gradle Sync.
4. Выбрать эмулятор или устройство с API 26+.
5. Запустить приложение через специальную кнопку.

## Backend/data-layer

Основной backend-слой приложения находится в [app/src/main/java/com/example/fitme/data](app/src/main/java/com/example/fitme/data)
```text
data/
├── AppDatabase.kt               # RoomDatabase, список таблиц, singleton базы
├── dao/                         # SQL-запросы и DAO-интерфейсы
├── entities/                    # Room-сущности, enum, converters, relations
├── models/                      # DTO/модели для выдачи данных в UI
├── repositories/                # бизнес-логика и операции над данными
└── seed/                        # стартовое заполнение базы данных
```

Главные сущности базы данных:

- `User` - профиль пользователя и активный план.
- `Plan` - тренировочный план.
- `WorkoutTemplate` - шаблон тренировки внутри плана или встроенный шаблон.
- `Exercise` - справочник упражнений.
- `ExerciseToDo` - упражнение в конкретном шаблоне с параметрами планирования.
- `WorkoutSession` - фактически созданная тренировочная сессия.
- `Note` - один выполненный подход в рамках сессии.

## UI-слой

UI находится в [app/src/main/java/com/example/fitme/ui](app/src/main/java/com/example/fitme/ui).

```text
ui/
├── MainScreen.kt                # корневой Compose-экран и NavHost
├── navigation/Screen.kt         # список маршрутов приложения
├── screens/                     # экраны и ViewModel-классы
└── theme/                       # тема, цвета, типографика, настройки темы
```

Точка входа приложения - [MainActivity.kt](app/src/main/java/com/example/fitme/MainActivity.kt).
